# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.40**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.40-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.40/RaPiDSSH-v1.4.40-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.40:

• Split Terminal (Side-by-Side / Multi-Pannello): suddivisione orizzontale o verticale della scheda terminale SSH con splitter trascinabile in tempo reale per lavorare contemporaneamente su due console dello stesso host.
• Duplica Sessione in Nuova Scheda: comando rapido con clic destro sulla scheda SSH per clonare al volo una sessione in un tab indipendente con le stesse credenziali ereditate.
• Memorizzazione Monitor e Geometria Multi-Monitor: alla riapertura l'applicazione ripristina fedelmente il monitor e la posizione della finestra precedente, con fallback intelligente sul display primario in caso di monitor disconnesso.
