# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.75**
- **Data rilascio**: 2026-11-11
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.75-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.75/RaPiDSSH-v1.4.75-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.75:

• Nuova Utility Ping Continuo Multi-Host & Scanner di Sottorete (Ping Sweep):
  - Finestra di Ping Avanzata: si apre come finestra flottante indipendente con supporto '📌 Sempre in primo piano' (Topmost) e pulsante '📥 Riaggancia come Scheda' per integrarla nei tab principali di RaPiDSSH (con supporto pop-out inverso).
  - Vista Divisa Multi-Ping Continuo: possibilità di monitorare contemporaneamente più host/IP in parallelo (split card view), con grafici istogramma di latenza in tempo reale, statistiche Tx/Rx/Lost/Min/Avg/Max e log a scorrimento.
  - Scanner di Sottorete Locale (Ping Sweep): rilevamento automatico della subnet attiva con 4 campi di inserimento IPv4 veloci (avanzamento automatico), numero di tentativi e timeout configurabili.
  - Tabella Risultati Intelligente: indicatori grafici 🟢 Online e 🔴 Offline, latenza media, risoluzione DNS inversa automatica in background, filtri in tempo reale, esportazione CSV e comandi contestuali per avviare il ping continuo o creare un nuovo server precompilato nell'albero di RaPiDSSH.
  - Scorciatoia Globale: richiamabile tramite menu 'Strumenti -> Ping Continuo & Scanner di Rete...', pulsante rapido nella barra strumenti e scorciatoia 'Ctrl+Shift+P'.
