# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.47**
- **Data rilascio**: 2026-11-02
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.47-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.47/RaPiDSSH-v1.4.47-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.47:

• Gestione Rapida Windows Integrata: nuova interfaccia ultra-rapida accessibile da 'Strumenti -> ⚡ Gestione Rapida Windows' e dal menu contestuale del server, per amministrare server Windows remoti senza attendere il caricamento pesante dei tool MMC standard.
• ⚙️ Servizi Windows: monitoraggio in tempo reale, ricerca istantanea, filtri per stato (🟢 Esecuzione, ⚪ Arrestato, ecc.) e controllo operativo immediato (Avvia, Arresta, Riavvia) con autenticazione remota integrata.
• 📋 Registro Eventi: lettura veloce e ottimizzata dei log remoti (System, Application, Security) con filtri per gravità (Errori, Avvisi, Info) e finestra temporale selezionabile.
• 👥 Utenti e Gruppi Locali: visualizzazione immediata dello stato degli account (attivo, disabilitato, bloccato/lockout) e appartenenza ai gruppi locali.
• 💾 Dischi e Condivisioni SMB: monitoraggio visivo dello spazio disco (barre di avanzamento colorate) e lista condivisioni di rete con apertura diretta in Esplora Risorse.
