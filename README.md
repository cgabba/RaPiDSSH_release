# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.28**
- **Data rilascio**: 2026-10-29
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.28-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.28/RaPiDSSH-v1.4.28-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.28:

  • Tag di Sistema Automatico 'Documentato' (📝): introdotto un tag di sistema gestito dinamicamente dall'applicazione per tutti i server con note o documentazione compilata. Il tag raggruppa automaticamente i server nell'albero delle connessioni sotto 'TAG ➔ 📝 Documentato'
  • Gestione Riservata: il tag è interamente controllato dal sistema e non può essere impostato o rimosso manualmente dall'utente
  • Sincronizzazione Immediata: all'aggiunta, modifica o cancellazione delle note nella scheda del server, il tag viene sincronizzato in tempo reale aggiornando l'albero e i filtri di ricerca
