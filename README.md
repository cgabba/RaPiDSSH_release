# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.73**
- **Data rilascio**: 2026-11-10
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.73-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.73/RaPiDSSH-v1.4.73-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.73:

• Pulizia Menu Contestuale File e Cartelle: rimossi i comandi 'Nascondi questa cartella' e 'Cartelle di Sistema' dal menu contestuale del file di connessione (.enc) e delle cartelle utente, riservandoli rigorosamente alle sole Cartelle di Sistema.
• Comando 'Proprietà' sul File di Connessione: aggiunto il comando Proprietà sul menu contestuale del file database che permette di personalizzare icona, nome e impostare le credenziali predefinite a livello di intero archivio.
• Ereditarietà Credenziali dalla Mamma (File .enc): abilitata per le cartelle e i server creati direttamente nella root del file la possibilità di ereditare automaticamente le credenziali definite a livello di file, con preview e risoluzione a cascata naturale.
