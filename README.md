# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.86**
- **Data rilascio**: 2026-11-13
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.86-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.86/RaPiDSSH-v1.4.86-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.86:

• Fluidità 60/144 fps VSync & Antialiasing Sub-Pixel: migrazione del motore Matrix a CompositionTarget.Rendering con delta-time continuo e scorrimento sub-pixel; rimossa la scalettatura dei caratteri con font vettoriali moderni (Yu Gothic / Meiryo / Consolas) e TextRenderingMode.Grayscale.
• Menu Segreto 'Matrix Subsystem Console': accessibile con 5 click rapidi sulla tazzina '☕' o scorciatoia Ctrl+Shift+M per personalizzare frasi da trasmettere, frequenza di comparsa e palette di colori (Verde Matrix, Cyberpunk Cyan, Amber CRT, Red Alert).
• Frasi Personalizzate con Lettura dall'Alto in Basso: proiezione periodica di frasi personalizzate che scendono leggibili rigorosamente dall'alto verso il basso in bianco brillante.
