# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.52**
- **Data rilascio**: 2026-11-04
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.52-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.52/RaPiDSSH-v1.4.52-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.52:

• Cartella di Sistema Connessioni Recenti: introdotta la cartella speciale '🕒 Connessioni Recenti' nell'albero che tiene traccia automaticamente delle ultime 5 connessioni aperte con persistenza tra i riavvii.
• Mostra / Nascondi Cartelle di Sistema: possibilità di nascondere o mostrare singolarmente ciascuna cartella speciale (Recenti, Preferiti, Connessioni Attive, Tutti i Server, Tag, Griglie Salvate) tramite il pulsante ⚙️ sopra l'albero, dal menu contestuale tasto destro sull'albero e dal menu 'Visualizza'.
• Evidenziazione Tab Attivo: riprogettato lo stile delle schede di sessione con indicatore superiore ad alto contrasto di 3px, bordo evidenziato, testo in grassetto e risalto visivo immediato.
