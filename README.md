Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

- **Data rilascio**: 2026-11-09

### Novità di questa versione:
Novità di RaPiDSSH v1.4.67:

• Motore Crittografico UltraVNC MS-Logon II (d3des AT&T): implementato il motore crittografico dedicato UltraVncCrypto replicando fedelmente l'algoritmo d3des (AT&T Laboratories Cambridge) impiegato dai sorgenti UltraVNC per l'autenticazione MS-Logon II (Tipo 113). Risolve il disallineamento della schedulazione delle sottochiavi DES standard, garantendo l'autenticazione trasparente e senza errori verso server Windows in dominio o locali.
