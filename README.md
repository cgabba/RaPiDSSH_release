# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.56**
- **Data rilascio**: 2026-11-05
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.56-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.56/RaPiDSSH-v1.4.56-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.56:

• Chiusura Automatica Scheda su Disconnetti: effettuando il clic destro sull'intestazione del tab di sessione e selezionando "Disconnetti", la sessione viene terminata e la scheda chiusa istantaneamente senza dover cliccare due volte.
• Grigino Dinamico Contestualizzato nell'Albero: l'attenuazione visiva (dimming) dell'albero server si attiva unicamente quando una sessione remota è visualizzata sullo schermo. Quando si consulta la scheda tecnica del server o si naviga l'inventario, l'albero ripristina all'istante il suo colore neutro di riposo.
• Perfezionamento Contrasti e Bonifica Colori Hardcoded: bonificate le stringhe di colore hardcoded sui temi Scuro e Chiaro (inclusi pulsanti di modifica credenziali, stato aggiornamenti e header di sezione) con il nuovo set semantico ThemeWarningForeground e stili reattivi ad alto contrasto.
