# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.60**
- **Data rilascio**: 2026-11-05
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.60-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.60/RaPiDSSH-v1.4.60-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.60:

• Intercettazione Globale Sequenza Tasti & Log Dettagliati: introdotto l'hook a livello di thread (ComponentDispatcher) con stato asincrono e tolleranza temporale (2000ms) per intercettare l'attivazione della finestra video flottante da qualsiasi contesto di focus dell'applicazione (inclusi controlli e terminali). Aggiunti log di debug completi per tracciare ogni passaggio della sequenza.
• Menu Contestuale Dark su Tutti i Campi di Testo: configurato menu contestuale scuro esplicito (Taglia, Copia, Incolla, Seleziona tutto) per tutti i TextBox dell'applicazione, inclusi appunti e note dei server, eliminando definitivamente il fallback a popup chiari di sistema.
