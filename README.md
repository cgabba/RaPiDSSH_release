# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.36**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.36-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.36/RaPiDSSH-v1.4.36-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.36:

    Correzione Visibilità Tag nei Menu Contestuali: risolto il problema del testo bianco su bianco per i tag di sistema (Always On, Spento, No Logoff) e freccia dei sottomenu nel tema chiaro, garantendo massimo contrasto sia in hover che a riposo.
    Picker Credenziali per Connessione VNC Rapida: introdotto un selettore a discesa (dropdown) che raccoglie in automatico tutte le credenziali salvate negli archivi aperti e nelle cartelle/server, permettendo di scegliere comodamente quale password utilizzare (o digitare una password manuale) senza forzature.
    Accesso alla Scheda Server dal Tab Connesso: aggiunta la possibilità di aprire o visualizzare direttamente la Scheda Informativa (Dashboard) del server da qualsiasi tab di connessione attiva (tasto destro sull'intestazione del tab o pulsante dedicato nella barra superiore della sessione RDP, SSH e Telnet).
