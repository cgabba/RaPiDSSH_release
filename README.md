# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.91**
- **Data rilascio**: 2026-11-16
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.91-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.91/RaPiDSSH-v1.4.91-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.91:

• Gestione Server con Tag 'Spento':
  - Stile Barrato & Attenuato nell'Albero: i server con tag 'spento' vengono visualizzati nell'albero delle connessioni con il nome barrato (strikethrough) e opacità attenuata al 55% per un colpo d'occhio immediato dello stato offline.
  - Titoli Scheda e Tab Barrati: il nome del server appare barrato e attenuato anche nel titolo principale della Scheda del Server e negli header delle schede aperte.
  - Conferma di Sicurezza alla Connessione: richiesta esplicita di conferma prima di avviare una sessione (doppio clic, menu contestuale, 'Accedi come...', SFTP o dashboard) verso macchine contrassegnate come spente.
