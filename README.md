# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.63**
- **Data rilascio**: 2026-11-05
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.63-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.63/RaPiDSSH-v1.4.63-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.63:

• Modalità '☕ Pausa Caffè' (Screen Lock Non Distruttivo): introdotto il pulsante '☕ Pausa Caffè' (e combinazione rapida Ctrl+L) che blocca e oscura completamente l'interfaccia dell'applicazione dietro una schermata protetta con richiesta di Master Password, mantenendo attive e connesse in background tutte le sessioni SSH, RDP e SFTP.
• Blocco Automatico per Inattività (Temporizzato): configurabile nelle Impostazioni (scheda Sicurezza) per bloccare automaticamente l'app dopo 5, 10, 15, 30 o 60 minuti di inattività tramite rilevamento intelligente del tempo di idle.
• Ripristino Sessioni alla Riapertura: la chiusura da 'File -> Esci' preserva correttamente lo snapshot di tutte le sessioni attive, proponendo la finestra di ripristino guidato al successivo avvio.
• Allineamento Pixel-Perfect delle Voci di Menu: uniformati i template DarkSubmenuItemTemplate e DarkSubmenuHeaderTemplate in App.xaml eliminando gli spazi vuoti asimmetrici per le icone e garantendo un allineamento visivo impeccabile in tutti i menu a tendina e contestuali.
