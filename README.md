# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.57**
- **Data rilascio**: 2026-11-05
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.57-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.57/RaPiDSSH-v1.4.57-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.57:

• Interfaccia di Sicurezza & Retro Terminal Easter Egg: introdotta la schermata di sicurezza retro vintage 'Central Park Control Console' (con grafica vintage Mac System 7, typewriter dei comandi e cascata) attivata dopo tentativi ripetuti di inserimento password errata.
• Finestra Video Flottante: supporto alla riproduzione fluida di video multimediali in popup flottante (Picture-in-Picture) con chiusura automatica al termine.
• Risorse Incorporate Cifrate/Effimere: i file multimediali sono incorporati direttamente nell'eseguibile (nessun file video esposto nella directory dell'applicazione), con estrazione ed eliminazione volatile al termine dell'esecuzione.
