# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.41**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.41-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.41/RaPiDSSH-v1.4.41-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.41:

• Split Terminal Simmetrico e Bilanciato: layout riprogettato con barra superiore unificata e pannelli perfettamente speculari, ciascuno con sub-header dedicato, indicatore del terminale attivo ed evidenziazione dei bordi con il colore d'accento del tema.
• Gestione Intelligente dei Comandi Split: digitazione password, pulisci schermo, zoom e scorciatoie da tastiera instradati automaticamente al terminale selezionato; ripristino immediato a schermo intero alla digitazione di 'exit' nella seconda console.
