### Novità di questa versione:
Novità di RaPiDSSH v1.4.90:

• Modifica Rapida Nome Server in Scheda Dashboard: aggiunta icona a matita interattiva (e doppio clic sul titolo) nella barra d'intestazione della Scheda del Server per rinominare il server direttamente in-place senza aprire le proprietà.
• Fix Chiamata LoggerService: corretta invocazione di LoggerService.Instance.LogInfo durante l'evento di rinomina per ripristinare il flusso CI di compilazione e rilascio automatico.
