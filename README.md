# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.100**
- **Data rilascio**: 2026-11-27
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.100-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.100/RaPiDSSH-v1.4.100-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.100:

• Nuovo Generatore di Password Sicure Standalone (Ctrl+Shift+G):
  - Finestra dedicata accessibile da Strumenti, barra superiore (🔐 Password) e scorciatoia Ctrl+Shift+G.
  - Generazione CSPRNG (RandomNumberGenerator) con personalizzazione lunghezza (4-128), set di caratteri, esclusione caratteri ambigui e modalità simboli sicuri per terminale/script.
  - Indicatore di entropia/robustezza in tempo reale e pulizia automatica degli appunti configurabile (10-120s).
