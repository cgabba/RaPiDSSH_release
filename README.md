# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.38**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.38-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.38/RaPiDSSH-v1.4.38-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.38:

• Revisione Completa Temi Chiaro e Scuro: audit e normalizzazione dei colori su tutte le finestre, schede, dashboard e finestre modali con risorse semantiche dinamiche.
• Correzione Ripristino Sessioni (RestoreSessionsDialog): risolto il problema dei testi chiari non leggibili su sfondo bianco e normalizzati i pulsanti di azione ('Non ripristinare' e 'Ripristina Selezionate') ad alto contrasto.
• Inizializzazione Anticipata del Tema (App.OnStartup): il tema selezionato dall'utente viene caricato prima dell'apertura di qualsiasi finestra (inclusa la Master Password iniziale), eliminando ogni incoerenza cromatica o sfarfallio all'avvio.
• Dialoghi e Strumenti Aggiornati: uniformati i colori di Modifica Server, Proprietà Cartella, Gestione Tag, Wizard Importazione CSV, Impostazioni Debug, Visualizzatore File Remoti e finestre flottanti Ping ed SFTP.
• Pulsanti di Azione e Contrasto Ottimizzato: garantito contrasto elevato con testo bianco permanente su tutti i pulsanti primari (blu/verde) e bordi definiti per i pulsanti secondari in entrambe le modalità.
