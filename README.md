# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.31**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.31-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.31/RaPiDSSH-v1.4.31-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.31:

  • Nuova Finestra Credenziali Protetta (ViewCredentialsDialog): quando si clicca su 'Mostra Password' nella dashboard del server, appare un dialogo moderno dedicato con 3 campi distinti (Dominio, Utente, Password) ciascuno dotato di pulsante copia rapida. La password rimane mascherata (••••••) per proteggere da shoulder-surfing e può essere rivelata tenendo premuto o cliccando l'icona occhietto (👁️) oppure tramite la spunta 'Mostra password in chiaro'
  • Spostamento Server Multipli (Multi-Select Drag & Drop): corretta la gestione del trascinamento quando sono selezionati più server tramite Ctrl+Click o Shift+Click; il drop in una cartella sposta ora l'intero gruppo di server selezionati preservando la selezione attiva e ri-cifrando automaticamente le credenziali se lo spostamento avviene tra file .enc distinti
