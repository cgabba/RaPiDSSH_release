# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.43**
- **Data rilascio**: 2026-11-02
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.43-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.43/RaPiDSSH-v1.4.43-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.43:

• Finestre Flottanti Indipendenti (Dock / Undock): possibilità di sganciare qualsiasi sessione attiva (SSH, RDP, Telnet, VNC, Griglie, SFTP, Ping) in una finestra indipendente separata tramite click destro sul server o sulla scheda, pulsante rapido 🗗 o drag&drop della linguetta. Riaggancio immediato con un clic.
• Chiusura Controllata Finestre Flottanti: la chiusura con ✕ della finestra indipendente gestisce la disconnessione e i prompt di logoff identicamente alle schede principali.
• Fix Contrasto Proprietà Cartella & Dialoghi: griglia icone e intestazioni del dialogo proprietà cartella convertite a temi dinamici per una perfetta visibilità in modalità chiara e scura.
