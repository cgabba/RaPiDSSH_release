# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.97**
- **Data rilascio**: 2026-11-23
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.97-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.97/RaPiDSSH-v1.4.97-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.97:

• Finestra Flottante Post-Install Linux, Comandi Rapidi e Guide Operative (Runbook):
  - Nuova utility avanzata per amministratori di sistema accessibile da Strumenti, toolbar e con la scorciatoia globale Ctrl+Shift+L.
  - Sezione Comandi Rapidi (One-Liner) categorizzati (Aggiornamenti, Virtualizzazione/Guest Tools, Utility essenziali, Monitoraggio, Hardening SSH).
  - Sezione Procedure e Guide Operative (Playbook Step-by-Step) con spiegazioni chiare e comandi in sequenza, inclusa la procedura completa di Rescan SCSI e Resize LVM su VMware (growpart, pvresize, lvextend, resize2fs/xfs_growfs).
  - Esecuzione interattiva diretta nella sessione terminale attiva con sostituzione intelligente dei segnaposto ({host}, {ip}, {name}, {user}) e fallback automatico negli appunti.
  - Personalizzazione totale (aggiunta, modifica, eliminazione, ripristino default) salvata su 'post_install_commands.json' nella root dell'app e inclusa nel backup completo cifrato (.rsbak).
