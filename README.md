# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.37**
- **Data rilascio**: 2026-10-30
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.37-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.37/RaPiDSSH-v1.4.37-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.37:

    Correzione Grafica Finestra Master Password (Autenticazione): eliminato il testo bianco su bianco nel titolo, i campi password scuri e i pulsanti a basso contrasto; la finestra ora rispetta fedelmente la palette del tema chiaro e del tema scuro.
    Ottimizzazione Finestre di Aggiornamento: unificate le finestre di notifica aggiornamenti, impostazioni aggiornamenti e attesa download/chiusura con pennelli dinamici per testi, percentuali, barre di avanzamento e pulsanti di azione.
    Uniformità Stili Finestre Modali: aggiornati anche i dialoghi di modifica master password, input tag, nome griglia e ripristino sessioni per una perfetta leggibilità in modalità chiara.
