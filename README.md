# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.24**
- **Data rilascio**: 2026-10-29
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.24-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.24/RaPiDSSH-v1.4.24-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.24:

  • Autologin Sessioni Telnet: implementata procedura automatica e sequenziale di autenticazione Telnet con rilevamento intelligente dei prompt (Username:, login:, Password:, Passcode:), pulizia sequenze di escape ANSI e gestione banner iniziali ('Press any key to continue')
  • Pulsanti Rapidi Credenziali Telnet: aggiunti pulsanti dedicati nella barra della sessione per '⚡ Autologin', '👤 User' e '🔑 Password' con disattivazione trasparente in caso di digitazione manuale dell'utente
