# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.20**
- **Data rilascio**: 2026-10-29
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.20-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.20/RaPiDSSH-v1.4.20-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.20:

  • Supporto Nativo Protocollo Telnet (RFC 854): aggiunta gestione completa di sessioni Telnet (porta 23 di default o personalizzata) con icona 📟, negoziazione automatica opzioni (ECHO, SGA, NAWS per ridimensionamento finestra, Terminal-Type), supporto completo scorciatoie da tastiera, ricerca nel terminale (Ctrl+Shift+F), buffer di scorrimento e pulsante "🔑 Digita Password"
  • Integrazione Globale Telnet: supporto completo nelle schede sessione, in Vista a Griglia (Grid View), import/export CSV e finestra di monitoraggio riavvio
