# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.80**
- **Data rilascio**: 2026-11-11
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.80-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.80/RaPiDSSH-v1.4.80-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.80:

• Utility Multi-Ping - Registrazione Log su File: aggiunta la registrazione continua dei ping su file (.log) indipendente per ogni singola card/host, con timestamp completo e statistiche finali.
• Utility Multi-Ping - Allarmi Acustici Intelligenti: avviso acustico immediato in caso di caduta connessione o mancata risposta (ripetuto ogni 10 secondi finché persiste il disservizio) e segnale sonoro di ripristino quando l'host torna raggiungibile.
• Ergonomia e Controlli Audio: la finestra di ping si apre silenziata (Muto) di default per evitare disturbi indesiderati; pulsante Master Audio per abilitazione globale e controlli individuali per silenziare singole macchine.
