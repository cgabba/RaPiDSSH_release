# RaPiDSSH Distribution & Release Repository

Repository ufficiale per la distribuzione e l'aggiornamento automatico di **RaPiDSSH** (Remote Desktop & SSH Session Manager).

## 🚀 Ultima Versione: **v1.4.46**
- **Data rilascio**: 2026-11-02
- **Pacchetto Portable (Zero Installazione)**: [Scarica RaPiDSSH-v1.4.46-Portable.zip](https://github.com/cgabba/RaPiDSSH_release/releases/download/v1.4.46/RaPiDSSH-v1.4.46-Portable.zip)
- **Feed Manifest Aggiornamenti**: [version.json](https://raw.githubusercontent.com/cgabba/RaPiDSSH_release/main/version.json)

### Novità di questa versione:
Novità di RaPiDSSH v1.4.46:

• Split-Tab Unificata Sessione & Scheda: ogni sessione remota attiva (SSH, RDP, Telnet, VNC) presenta una scheda fusa con a sinistra il pulsante compatto '📋' (Scheda informativa e note) e a destra la connessione live.
• Passaggio Immediato a 1 Click: cliccando su '📋' o sul nome del server si commuta all'istante la vista tra la dashboard tecnica e il terminale/desktop remoto, mantenendo la sessione attiva e connessa in background senza dispersione di schede.
• Ciclo di Vita Unificato: chiusura (X) e spostamento della scheda gestiscono simultaneamente sia la connessione sia la relativa scheda, con pulizia totale dei controlli grafici.
